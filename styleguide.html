Cómo Aprovechar Flex y Grid en tus Views

El proyecto ya tiene patrones de flex/grid que puedes reutilizar. Aquí te muestro cómo aprovecharlos:

Patrón 1: Layout Flex Vertical (Columnas) - Como .form

<div style="display: flex; flex-direction: column; gap: 15px; align-items: center;">
  <h2>Título</h2>
  <input type="text" placeholder="Campo 1">
  <input type="text" placeholder="Campo 2">
  <button class="boton">Enviar</button>
</div>

✅ Dónde usas esto: Formularios, secciones de contenido vertical, formularios de login

Patrón 2: Layout Flex Horizontal (Filas) - Como .tarjeta--fila

<div style="display: flex; align-items: center; gap: 10px;">
  <img src="foto.jpg" style="width:50px; border-radius: 50%;">
  <div>
    <h3>Nombre Usuario</h3>
    <p>Información</p>
  </div>
  <button style="margin-left: auto;">Acción</button>
</div>

✅ Dónde usas esto: Listas de usuarios, items de historial, filas de datos

Patrón 3: Layout Flex Centrado - Como .flex--center (implícito)

<div style="display: flex; justify-content: center; align-items: center; height: 200px;">
  <div style="text-align: center;">
    <i class="ri-check-line" style="font-size: 40px; color: var(--color-verdoso);"></i>
    <h2>¡Proceso Completado!</h2>
  </div>
</div>

✅ Dónde usas esto: Mensajes de éxito, pantallas vacías, contenido centrado

Patrón 4: Layout Flex Space-Between - Como .gestionarAfecciones__header

<div style="display: flex; justify-content: space-between; align-items: center; width: 100%;">
  <h3>Título Sección</h3>
  <button class="boton" style="width: auto;"><i class="ri-add-line"></i></button>
</div>

✅ Dónde usas esto: Headers de secciones, encabezados con botones, navegación

Patrón 5: Layout Grid 2 Columnas - Como tarjeta-introduccion

<div style="display: grid; grid-template-columns: 1fr 1fr; gap: 10px; align-items: center;">
  <input type="text" placeholder="Nombre">
  <input type="text" placeholder="Apellido">
  <input type="email" placeholder="Email">
  <input type="tel" placeholder="Teléfono">
</div>

✅ Dónde usas esto: Formularios con múltiples campos, grillas de datos, layouts responsivos

Patrón 6: Layout Flex Wrap - Para Listas Flexibles

<div style="display: flex; flex-wrap: wrap; gap: 10px;">
  <span class="seccion__tarjeta seccion__tarjeta--azul">
    <i class="ri-user-line"></i>
    <span>Usuario</span>
  </span>
  <span class="seccion__tarjeta seccion__tarjeta--verde">
    <i class="ri-check-line"></i>
    <span>Activo</span>
  </span>
</div>

✅ Dónde usas esto: Tags/etiquetas, badges, secciones que se adapten

Patrón 7: Flex con Grow para Espacios Dinámicos

<div style="display: flex; gap: 10px; align-items: center;">
  <span>Nombre:</span>
  <input style="flex-grow: 1;">  <!-- Ocupa todo el espacio -->
  <button class="boton" style="width: auto;">Guardar</button>
</div>

✅ Dónde usas esto: Campos con botones, inputs que ocupan espacio disponible

Patrón 8: Grid Auto-Responsive - Como dashboard

<div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); gap: 10px;">
  <div class="tarjeta">Card 1</div>
  <div class="tarjeta">Card 2</div>
  <div class="tarjeta">Card 3</div>
</div>

✅ Dónde usas esto: Dashboards, galerías, layouts que se adaptan automáticamente

💡 Resumen Rápido de Propiedades que Necesitas

Propiedad Propósito Valores Comunes
display: flex Activa flexbox flex | grid | block
flex-direction Dirección de items row | column
justify-content Alineación horizontal center | space-between | flex-start | flex-end
align-items Alineación vertical center | flex-start | flex-end | stretch
gap Espacio entre items 5px | 10px | 15px | 20px
flex-grow Crece si hay espacio 0 | 1
flex-wrap Items pasan a siguiente línea wrap | nowrap
grid-template-columns Define columnas del grid 1fr 1fr | repeat(auto-fit, minmax(250px, 1fr))

💡 Tips para Usar Correctamente

  • Reutiliza boton + modificador en lugar de crear clases nuevas
  • Usa tarjeta para todos los contenedores con sombra
  • Combina clases: boton boton--azul
  • Usa variables CSS para colores: var(--color-primario)
  • Mantén los nombres cortos pero descriptivos (BEM)
  • No crees clases como boton-verde, usa boton boton--azul
  • Evita estilos inline
  • No duplicates CSS, reutiliza componentes
  • No uses nombres en otros idiomas mixtos
  • No hagas clases muy específicas (ej: boton-usuario-home-crear)

Ejemplo de Uso en HTML

<!-- Formulario con input -->
<div class="form">
  <h2 class="form__titulo">Mi Formulario</h2>
  <div class="form__inputBox">
    <i class="ri-user-line"></i>
    <input type="text" placeholder="Nombre completo">
  </div>
  <button class="boton boton--azul">Enviar</button>
</div>

<!-- Tarjeta con contenido -->
<div class="tarjeta tarjeta--completa">
  <div class="tarjeta__titulo">Información</div>

</div>

<!-- Modal de visualización -->
<div class="modalVer">
